- **Fixed CodeBuddy `400 model [default-model] service info not found`**: Stops forwarding the client-side placeholder `default-model` to `codebuddy --model` or `set_model`; recycles the idle pre-warmed CodeBuddy process when switching models before the first turn (avoiding sessionless `set_model` rejections); resolves Auto back to the CLI's concrete default model on active sessions.
- **Enabled In-App Auto-Update & Update Notifications**: Wired up `UpdateService` and `UpdateController` in release builds so Ayte checks GitHub Releases automatically, verifies Ed25519-signed installers, notifies in the main window, and updates on restart; replaced legacy `kestrel.dev` update copy with GitHub Releases.
- **Improved CodeBuddy Process & Environment Handling**: Added POSIX descendant process-tree cleanup on respawn/close and case-insensitive home environment lookup.
