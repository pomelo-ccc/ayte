### Ayte 2.0.4 更新说明

- **四大内核能力全面拉齐与 `agy` 跨会话管理**：新增本地 Streamable-HTTP MCP 桥接（`AyteSdkMcpBridge`），将 `SessionTools` 跨会话管理、共享 `<agent-message>` 解析与跨内核会话路由全面打通至 Antigravity（`agy`）与 Codex；新增 `agy` `/` 斜杠命令与项目/全局/插件 Skills 自动补全，补全权限模式映射、编辑/计划钩子、MCP 状态/重连/认证及多账号用量；全面对齐 CodeBuddy 与 Codex 目录、历史记录、会话分支/重命名、审批/Diff 及 Windows `.cmd`/`.ps1` 启动与健康重启。
- **多内核统一工作台、任务队列与自动化升级**：将全文会话搜索（`ConversationSearch`）、自定义配置（`CustomizationStore`）与扩展开关（`ExtensionSwitches`）扩展至全部四大内核，补全 Debug REPL 惰性求值；强化任务队列（模型/推理强度隔离、合并前脏工作区检查与 `GIT_INDEX_FILE` 隔离）、自动化规则视图与 `create_automation` 工具，以及 `AyteIpcServer` / `AcpAgentService` 稳定性。
- **Studio 工作流画布 v2 与端到端实时语音模式**：升级并行 DAG 执行引擎、AI 工作流构建器与跨平台支持；新增流式 SenseVoice STT、Edge Neural TTS、流式 C++ TTS、在线语音模型安装器、AI 文本润色、自适应 VAD、语音快捷指令、免提对话模式及 macOS 原生 AVFoundation 音频引擎。
- **macOS 原生菜单栏状态弹窗（Tray Popover）**：全新菜单栏弹出面板，实时聚合展示等待输入、运行中、已完成会话与已打开窗口，支持一键切换会话、新建对话与打开设置。

> **macOS 首次打开提示**：若未配置 Apple 开发者公证，其它 Mac 下载拖入 `Applications` 后若提示无法打开，在终端执行一次 `xattr -cr /Applications/Ayte.app` 即可正常启动。
