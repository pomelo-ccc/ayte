### Bug Fixes
- **Fix Missing Assistant Replies & False Auto-Compaction After Reopening Antigravity Sessions**:
  - Persist the bound Antigravity CLI conversation ID (`antigravity-conversation`) in the session log so reopening or restarting a session resumes its exact native `agy` context instead of spawning a fresh conversation with a truncated summary seed.
  - Generate globally unique synthetic turn, message, and tool IDs per `AntigravityTransport` instance and retry/failover attempt so new turns never collide with or silently overwrite earlier turns' items.
  - Emit real mid-turn auto-compaction boundaries chronologically *before* the post-compaction assistant reply (and persist them), while preventing false auto-compaction notices on freshly seeded conversations.
  - Make transcript branch resolution and history replay resilient to legacy duplicate `agy-*` UUIDs already on disk so previously hidden replies reappear cleanly when reopening affected sessions.
