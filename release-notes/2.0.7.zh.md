### 新功能与体验优化
- **OpenAI 兼容 TTS 支持服务端音色拉取、自定义音色 ID 与免 Key 服务**：语音设置页可自动探测并手动刷新服务端已有音色列表，支持下拉选择服务端音色 / OpenAI 预设或直接输入自定义音色 ID；局域网 / 自建免 Key TTS 接口留空 API Key 即可直接播报，并在省略 `/v1` 时自动兼容 `/v1/audio/speech` 与 WAV/OGG/FLAC 音频格式。
- **左侧会话列表新增项目下轻量化 Agent 子分组**：按项目分组且存在多个 Agent 时，在每个项目下以低对比度细线子标题区分 Antigravity / CodeBuddy / Claude Code / Codex 会话，按最近活跃 Agent 排序，支持独立折叠与右键筛选/归档，置顶卡片与悬停提示同步标明所属 Agent。

### 问题修复
- **修复模型「思考强度」二级菜单缺失**：支持解析 `reasoning: true` 与 `thinkingLevelMap`（包含 2 档可调模型如 DeepSeek-V4.1-Flash），不再被 CLI 返回的简化 `rawModels` 抹掉可调档位；仅支持固定单档推理的模型退化为只读提示（`固定 High（不支持调整）`），全 `null` / 仅 `off` 边界不渲染空面板。
- **修复重开 Ayte 后 CodeBuddy 会话消失**：新增 `CodeBuddyCatalog` 扫描并解析 `~/.codebuddy/projects/` 下的原生 JSONL 会话，完整翻译对话消息、思考过程与工具调用记录并支持分页加载，重命名时同步写入原生会话文件，重启后无缝恢复全部历史会话。
