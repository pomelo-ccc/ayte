### Features & Improvements
- **OpenAI-Compatible TTS Server Voice Discovery, Custom Voice ID & Keyless Support**: Voice settings now auto-fetch and refresh available voices from OpenAI-compatible/self-hosted TTS servers, support entering arbitrary custom voice IDs synced with the picker, allow keyless local/LAN TTS endpoints without an API key, auto-retry `/v1/audio/speech` on 404 when `/v1` is omitted, and sniff WAV/OGG/FLAC/MP3 audio headers.
- **Subtle Per-Agent Sub-Grouping Under Project Groups**: In the left sidebar's project view with multiple active agents, sessions are grouped under understated 20px hairline agent sub-headers (ordered by most recently active agent) with independent fold/expand and right-click filter/archive actions; pinned cards and hover tooltips also indicate the agent.

### Bug Fixes
- **Fixed Missing Reasoning Effort Submenu for 2-Tier & Fixed-Tier Models**: Parses boolean `reasoning: true` and `thinkingLevelMap` (keeping 2-tier models like DeepSeek-V4.1-Flash selectable), preserves known configurable efforts when live CLI `rawModels` omits `supportedEfforts`, degrades single-tier fixed reasoning models to a non-clickable read-only indicator, and avoids empty panels for all-null/`off`-only definitions.
- **Fixed CodeBuddy Sessions Disappearing After Restart**: Added `CodeBuddyCatalog` to discover, translate, paginate, and delete native CodeBuddy CLI transcripts under `~/.codebuddy/projects/`, persisting custom titles directly to the native transcript so sessions survive restarts cleanly.
