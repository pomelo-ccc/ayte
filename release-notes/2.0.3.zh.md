### Ayte 2.0.3 更新说明

- **2D 可执行工作流画布（DAG）全面升级**：支持多工作流并发执行与独立快照隔离、Studio 级右侧节点配置面板、工作流/节点双层模型路由、运行前快速参数弹窗、失败/任意节点断点续跑、运行历史持久化（`canvas_runs.json`）、留证截图/录屏一键回看、零 Token 直调 Jenkins API 部署模板与完成庆祝烟花提示。
- **四大原生内核 & CodeBuddy 多账号支持**：原生直连 Antigravity (`agy`)、CodeBuddy（支持 OAuth 多账号切换与额度展示）、Claude Code 与 Codex（支持动态模型列表与推理强度选择）。
- **工作台效率套件、内嵌浏览器与 Computer Use**：新增任务队列、自动化、资料库文档预览、分组标签、对话内交互式 UI 渲染（`json-render`）、macOS 原生内嵌浏览器与 Computer Use 驱动桥接（`libAyteNative.dylib`）。

> **macOS 首次打开提示**：若未配置 Apple 开发者公证，其它 Mac 下载拖入 `Applications` 后若提示无法打开，在终端执行一次 `xattr -cr /Applications/Ayte.app` 即可正常启动。
