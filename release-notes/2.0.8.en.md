### Features & Improvements
- **Structured Workflow Context Propagation & Approval Controls**: Canvas workflow runs now automatically extract `BUG_ID`, `BUG_GUID`, `BUG_TITLE`, `BUG_URL`, and `CHANGED_REPOS` into downstream template variables and shell environment variables, persist per-gate `{{<nodeId>.note}}` notes, support variable-to-variable `{{a ?? b}}` fallbacks, default approval gates to unlimited wait (`0`), refresh the pre-run dialog model badge live, and respect runtime `evidenceDir` overrides.
- **Hardened Built-In Bug Automation Workflow**: Switched headless ticket triage and status updates to direct bug tracker REST APIs with proxy bypass and cold-cache timeouts, added optional `bugId` targeting, scoped local LC/BC rebuilds to modified repositories, updated 4200/69 verification to Python Playwright and Jenkins REST APIs, and enabled strict `VERDICT: PASS/FAIL` gates across stages.

### Bug Fixes
- **Prevented Approval Timeouts from Firing Rejection Side-Effects**: Explicit approval timeouts now abort cleanly (`exitCode=124`) without executing `onFail` rejection branches, and intentional human rejection recovery nodes complete the run cleanly (`recoversFailure: true`).
- **Fixed Silent Headless Stream Errors & Trailing Output Drops**: `AcpAgentService` now detects `agy` `event: "error"` and non-`SUCCESS` result statuses as well as `claude`/`codebuddy` `is_error: true` results even on exit code 0, and drains stdout/stderr pipes before cancelling listeners so final NDJSON `result` frames are never lost.
