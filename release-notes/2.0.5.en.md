### Bug Fixes
- **Fixed Antigravity Context Usage Tracking & False Auto-Compaction**: Supports `agy`'s uncached-only `input_tokens` reporting alongside `cache_read_tokens` (while remaining compatible with legacy payloads), preventing uncached deltas from being zeroed out, preventing cache reads from being dropped when reading brain transcripts, eliminating false `compact_boundary` triggers and sudden context drops on high-cache turns, and removing synthetic category splits in the context popover when the backend does not report per-category breakdowns.
- **Fixed "Retry" on Historical Errors Resending the Latest Message**: Binds each error notice to its position in the conversation so clicking retry (or switching models to retry) resends the specific user message that triggered the error—including image attachments—instead of the latest prompt in the session, and hides retry controls for errors that precede any user message.

### UI Polish
- **Redesigned macOS Menu Bar Tray Icon**: Updated to a monochrome geometric `a` mark with a 4-point spark for cleaner appearance across light and dark menu bars.
- **Refined Composer Toolbar & Sidebar Grouping**: Streamlined composer controls and account quota badges, and improved sidebar kernel grouping and filtering.
