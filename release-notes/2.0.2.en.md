### What's New in Ayte 2.0.2

- **Native Google Antigravity (`agy`) Engine**: Persistent multi-turn `stream-json` sessions with multi-account OAuth quota refresh, accurate per-model context windows, and Argon 512K/900K compaction overrides.
- **Refined Workbench & Sidebar UI**: 1:1 Antigravity thin-stroke sidebar with pill selection, warm unified composer card with ghost toolbar controls, and customizable color themes (create, edit, delete).
- **Multi-Platform Releases & Signed Auto-Update**: Prebuilt installers for macOS (Apple Silicon & Intel), Windows (x64 & ARM64), and Linux (amd64 & arm64 `.deb` / `.tar.gz`), with Ed25519-signed in-app updates via GitHub Releases.

> **macOS First Launch Note**: On macOS without Apple notarization, run `xattr -cr /Applications/Ayte.app` once in Terminal after dragging `Ayte.app` into `Applications` if Gatekeeper blocks first launch.
