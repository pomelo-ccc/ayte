### What's New in Ayte 2.0.4

- **Full 4-Kernel Parity & Cross-Session Management for `agy`**: Added loopback Streamable-HTTP MCP bridging (`AyteSdkMcpBridge`) to connect `SessionTools`, cross-kernel routing, and shared `<agent-message>` parsing to Antigravity (`agy`) and Codex; added `agy` `/` slash command & project/global/plugin Skills autocomplete, permission mode mapping, edit/plan hooks, MCP status/reconnect/auth, and account quota tracking; brought CodeBuddy and Codex to full parity with live catalogs, history loading, fork/rename, approvals/diffs, Windows `.cmd`/`.ps1` process launching, and health restart.
- **Unified Multi-Kernel Workbench, Tasks & Automations**: Extended `ConversationSearch`, `CustomizationStore`, and `ExtensionSwitches` across `agy`, `codebuddy`, `codex`, and `claude-code`, and completed lazy Debug REPL evaluation; hardened `TaskQueueService` (`model`/`effort` isolation, pre-merge dirty tree check, `GIT_INDEX_FILE` isolation), `AutomationRule`/`AutomationsView`/`create_automation`, and `AyteIpcServer`/`AcpAgentService` reliability.
- **Studio Workflow Canvas v2 & Real-Time Voice Mode**: Added parallel DAG execution engine, AI workflow builder, and cross-platform support; introduced streaming SenseVoice STT, Edge Neural TTS, streaming C++ TTS, online model installer, AI proofreading, adaptive VAD, voice commands, hands-free conversation mode, and native macOS AVFoundation audio engine.
- **macOS Native Menu Bar Tray Popover**: New rich native tray popover displaying waiting, running, and finished agents alongside open windows with one-click navigation, new chat, and settings shortcuts.

> **macOS First Launch Note**: On macOS without Apple notarization, run `xattr -cr /Applications/Ayte.app` once in Terminal after dragging `Ayte.app` into `Applications` if Gatekeeper blocks first launch.
