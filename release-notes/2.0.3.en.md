### What's New in Ayte 2.0.3

- **Executable 2D Workflow Canvas (DAG)**: Concurrent multi-workflow execution with isolated run snapshots, Studio-grade right-hand Node Inspector, two-level model routing (workflow defaults + per-node overrides), pre-run quick parameter dialog, breakpoint resume from failed or any chosen node, persistent run history (`canvas_runs.json`), evidence/media quick-access chips, zero-token Jenkins API deploy template, and celebratory completion overlay.
- **4 Native Agent Kernels & Multi-Account Support**: Unified support for Antigravity (`agy`), CodeBuddy (with OAuth accounts & quota picker), Claude Code, and Codex (with live model catalog & reasoning effort controls).
- **Workspace Hub, Embedded Browser & Computer Use**: Added Task Queue, Automations, Library document preview, Grouped Tags, interactive UI Render (`json-render`), macOS embedded WKWebView browser, and Computer Use native bridge (`libAyteNative.dylib`).

> **macOS First Launch Note**: On macOS without Apple notarization, run `xattr -cr /Applications/Ayte.app` once in Terminal after dragging `Ayte.app` into `Applications` if Gatekeeper blocks first launch.
